# 二手书商城小程序 - 详细设计文档

## 一、项目概述

### 1.1 项目定位
这是一个基于微信小程序平台开发的**校园二手书交易平台**，旨在为大学生提供便捷的二手教材、参考书交易服务。通过整合微信生态，实现用户快速发布、浏览、购买二手书籍的闭环体验。

### 1.2 核心目标
- **解决痛点**：降低学生购书成本，提高教材循环利用率
- **目标用户**：在校大学生、研究生
- **核心价值**：便捷发布、快速交易、安全可靠

### 2.2 页面功能详解

#### 2.2.1 首页 (pages/index)
- **功能定位**：应用入口，展示平台核心价值
- **主要功能**：
  - 搜索栏：支持关键词搜索书籍
  - 分类导航：8大学科分类快速入口（数学、英语、计算机、物理、化学、经济、文学、其他）
  - 轮播图/精选推荐：展示最新上架的热门书籍
  - 悬浮购物车按钮：可拖拽的购物车快捷入口
  - 实时购物车数量显示

#### 2.2.2 书籍列表页 (pages/books)
- **功能定位**：书籍浏览与筛选中心
- **主要功能**：
  - 全量书籍展示，支持分页加载
  - 分类筛选：按学科快速筛选
  - 搜索功能：支持标题、作者、学科多字段搜索
  - 书籍卡片展示：封面、标题、价格、状态
  - 点击跳转详情页

#### 2.2.3 发布页 (pages/publish)
- **功能定位**：用户发布二手书籍
- **主要功能**：
  - 表单填写：书名、作者、学科、新旧程度、价格、原价、描述
  - 图片上传：支持书籍实拍图上传
  - 学科选择器：8大学科分类
  - 新旧程度选择：全新、几乎全新、良好、一般
  - 表单验证：必填项校验

#### 2.2.4 购物车页 (pages/cart)
- **功能定位**：购买前的商品管理
- **主要功能**：
  - 商品列表展示：图片、标题、价格、数量
  - 数量调整：增减商品数量
  - 单选/全选：批量选择商品
  - 批量删除：移除不需要的商品
  - 价格计算：实时计算选中商品总价
  - 结算跳转：生成订单

#### 2.2.5 个人中心 (pages/profile)
- **功能定位**：用户信息与交易管理
- **主要功能**：
  - 用户信息展示：头像、昵称、评分
  - 我的发布：管理已发布的书籍
  - 我的订单：查看购买记录
  - 交易统计：已售、已买数量
  - 设置选项：地址管理、账号设置

#### 2.2.6 书籍详情页 (packageA/pages/bookDetail)
- **功能定位**：商品详细信息展示
- **主要功能**：
  - 大图展示：书籍封面轮播
  - 详细信息：书名、作者、价格、新旧程度、描述
  - 卖家信息：头像、昵称、评分
  - 操作按钮：加入购物车、立即购买、收藏

## 三、技术架构

### 3.1 技术栈总览

```
┌─────────────────────────────────────────────────────────────┐
│                      技术架构图                              │
├─────────────────────────────────────────────────────────────┤
│  前端层                                                      │
│  ├── 微信小程序原生框架 (WXML + WXSS + JS)                    │
│  ├── 微信小程序云开发 SDK                                    │
│  └── 自定义组件库 (TabBar、Button、Card等)                    │
├─────────────────────────────────────────────────────────────┤
│  后端层 (云开发)                                              │
│  ├── 云函数 (Node.js)                                        │
│  ├── 云数据库 (MongoDB)                                      │
│  └── 云存储 (文件存储)                                        │
├─────────────────────────────────────────────────────────────┤

│  └── 微信登录 (OpenID获取)                                   │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 前端技术详解

#### 3.2.1 微信小程序框架
- **WXML**：页面结构描述语言，类似HTML
- **WXSS**：样式表语言，支持rpx响应式单位
- **JavaScript**：页面逻辑处理，采用ES6+语法
- **JSON配置**：页面和全局配置

#### 3.2.2 响应式设计
- 使用 **rpx** 单位实现屏幕自适应
- 基础宽度：750rpx = 屏幕宽度
- 支持媒体查询适配不同设备

#### 3.2.3 自定义组件
- **custom-tab-bar**：底部自定义导航栏
  - 5个Tab：首页、书籍、发布、购物车、我的
  - 中间发布按钮特殊样式（突出显示）
  - 选中状态高亮

#### 3.2.4 页面生命周期
- `onLoad`：页面加载，初始化数据
- `onShow`：页面显示，刷新数据、同步TabBar状态
- `onHide`：页面隐藏，保存状态
- `onUnload`：页面卸载，清理资源

### 3.3 后端技术详解 (微信云开发)

#### 3.3.1 云函数架构

| 云函数 | 功能 | 说明 |
|--------|------|------|
| `login` | 用户登录 | 获取OpenID，自动注册/登录 |
| `book` | 书籍管理 | 发布、查询、更新、删除书籍 |
| `cart` | 购物车 | 增删改查购物车商品 |
| `order` | 订单管理 | 创建、查询、取消订单 |
| `favorite` | 收藏功能 | 收藏/取消收藏书籍 |
| `initData` | 数据初始化 | 初始化测试数据 |
| `updateUserInfo` | 用户信息更新 | 更新用户资料 |

#### 3.3.3 云存储
- **用途**：存储用户上传的书籍图片
- **特点**：自动生成CDN链接，支持图片压缩
- **安全**：基于微信登录态的权限控制

### 3.4 核心功能实现

#### 3.4.1 用户登录流程
```
用户打开小程序
    ↓
调用 wx.login() 获取临时登录凭证 code
    ↓
调用云函数 login
    ↓
云函数获取微信上下文 (OpenID)
    ↓
查询数据库：用户是否存在？
    ↓
    ├── 新用户 → 创建用户记录 → 返回用户信息
    └── 老用户 → 更新登录时间 → 返回用户信息
    ↓
前端保存 OpenID 到本地存储
    ↓
完成登录，进入首页
```

#### 3.4.2 购物流程
```
浏览书籍
    ↓
点击"加入购物车"
    ↓
调用 cart 云函数 (action: add)
    ↓
检查书籍是否存在
    ↓
检查是否已在购物车
    ↓
    ├── 已存在 → 更新数量 (+1)
    └── 不存在 → 新增购物车记录
    ↓
返回成功提示
    ↓
进入购物车页面
    ↓
选择商品 → 调整数量/删除
    ↓
点击"结算"
    ↓
调用 order 云函数 (action: create)
    ↓
创建订单记录
    ↓
更新书籍状态为 sold
    ↓
更新用户交易统计
    ↓
清空购物车
    ↓
返回订单信息
```

#### 3.4.3 搜索功能实现
- **多字段搜索**：支持书名、作者、学科
- **模糊匹配**：使用正则表达式实现
- **分类筛选**：支持按学科快速筛选
- **排序**：按创建时间倒序排列

## 六、安全与性能

### 6.1 安全措施

#### 6.1.1 数据安全
- **OpenID隔离**：用户数据基于OpenID隔离
- **云函数权限**：敏感操作通过云函数执行
- **数据库权限**：严格的数据库访问规则

#### 6.1.2 输入验证
- **表单验证**：前端+后端双重验证
- **XSS防护**：文本内容转义处理
- **SQL注入防护**：使用云开发数据库，天然防注入

### 6.2 性能优化

#### 6.2.1 加载优化
- **分包加载**：使用subPackages分包，减少首屏加载时间
- **图片懒加载**：图片按需加载
- **数据分页**：列表数据分页加载

#### 6.2.2 渲染优化
- **列表渲染**：使用wx:key优化列表渲染
- **条件渲染**：合理使用wx:if和hidden
- **避免频繁setData**：合并数据更新

#### 6.2.3 存储优化
- **本地缓存**：使用wx.setStorage缓存数据
- **图片压缩**：云存储自动压缩图片
